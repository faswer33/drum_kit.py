# 🥁 Rock Drum Kit — играй на барабанах как рок-звезда

> «Барабаны — это сердце рока»

**Rock Drum Kit** — это набор консольных приложений для симуляции игры на ударной установке в стиле рок-музыки.  
Программа позволяет создавать и воспроизводить ритмические паттерны, имитируя звучание бас-барабана, малого барабана, хай-хэта, том-томов и тарелок.

## 🚀 Особенности
- 🥁 Симуляция основных элементов барабанной установки: бас-барабан, малый барабан, хай-хэт, томы, райд, крэш.
- 🎵 Генерация рок-ритмов (шаффл, прямой, половинный, блюзовый).
- 🎛️ Настройка темпа (BPM) от 60 до 200.
- 🖥️ Визуализация ударов в реальном времени (ASCII-арт или текстовый вывод).
- 💾 Сохранение и загрузка пользовательских паттернов.
- 🎮 Интерактивный режим: играйте на клавиатуре, как на барабанах.
- 📊 Отображение таймлайна с нотами.

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | `time`, `random`, `threading`        | `python drum_kit.py`                    |
| Go         | стандартная библиотека               | `go run drum_kit.go`                    |
| JavaScript | Node.js, `readline`                  | `node drum_kit.js`                      |
| Java       | стандартная библиотека               | `javac drum_kit.java && java drum_kit`  |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `rand`, `std::time`                  | `cargo run`                             |
| Ruby       | стандартная библиотека               | `ruby drum_kit.rb`                      |
| PHP        | стандартная библиотека               | `php drum_kit.php`                      |
